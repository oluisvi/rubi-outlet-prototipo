# Rubi Outlet · prévia conceitual

Vitrine responsiva de moda feminina com três estruturas selecionáveis: Editorial (campanha e narrativa), Vitrine direta (busca e categorias) e Lookbook (sequência visual). O seletor “Design” permite alternar a estrutura.

## Limites da demonstração

- Fotos e nomes são referências visuais, não representam o estoque ou produtos confirmados da Rubi.
- Não há preços, estoque, disponibilidade, tamanhos ou cores anunciados como fatos.
- Os seletores registram apenas preferências demonstrativas; os links abrem o Instagram da loja para a cliente consultar detalhes com a equipe.
- A página não tem carrinho nem integração de estoque. Dados reais devem ser confirmados pela Rubi antes de qualquer publicação comercial.

## Abrir

Abra `index.html` ou sirva a pasta: `python -m http.server 8768`.
